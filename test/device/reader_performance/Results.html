Each timed trial has its own book path. The table compares matching trial numbers, uses the first recorded matching operation in each trial and reports medians across pairs. Later setting changes and re-indexes stay in the raw file. The percentage is the median of each pair’s (B − A) / A. Negative means B took less time. If A records zero microseconds, the absolute medians include the pair and the percentage shows how many pairs had a usable baseline. Render, mixed-setting and migration rows remain in the raw file.
